## 📌 Laboratory Overview

A comprehensive collection of 22 foundational web development exercises, responsive user interface components, and client-side scripting demonstrations created as part of the Full Stack Development practicum.

## 📑 Component Showcase

- **Interactive Applications**: `Calculator.html` / `Calculator.css`
- **Responsive Layouts**: `RWD.html`, `navbar.html`, `Time table.html`
- **Forms & Validation**: `forms.html`, `Log in form.html`, `travel_reg_form.html`
- **Streaming UI Clones**: `Netflixx.html` / `Netflixx.css`
- **Foundational JavaScript**: `Basics of js.html`
